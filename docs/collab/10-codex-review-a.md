## Findings requiring changes

1. **FAIL — biological children reroll on every load (high).** `src/appearance/integration.py:96` loops over *all* biological children, including those with saved appearances, and calls `ensure_appearance` at line 102. Reproduced using a Player with one biological child, pickling `player.__dict__`, restricted loading, then `Player.load`: child's full appearance differs. Calling `migrate_appearances` a second time changes it again. This breaks the central lifetime identity/save compatibility requirement. Add save/reload coverage with biological children and repeated migration. Existing round-trip test (`tests/test_appearance.py:333`) has no children and misses this.

2. **FAIL — reconstructed relatives retain incorrect cached display names (high).** `src/people/classes/player.py:159`, `:167`, `:180` assign `firstname` after constructors calculate `.name`, without calling `update_name`. 3. **FAIL — seeded inheritance varies between Python processes (medium).** `src/appearance/generate.py:146` iterates `set(pool)` before consuming seeded RNG. Python hash randomization changes which mark receives which random draw. Reproduced three fresh processes with `PYTHONHASHSEED=1/2/3`, identical parents containing all five marks and `random.Random(7)`: inherited marks respectively `['scar_brow', 'birthmark', 'freckles']`, `['beauty_mark', 'birthmark', 'scar_brow']`, `['scar_brow', 'beauty_mark', 'birthmark']`. Use a stable unique ordering and add a subprocess test. Same-process determinism tests do not establish cross-run reproducibility.

4. **NEEDS-FIX — schema version is recorded but not enforced (medium).** `src/appearance/model.py:87` accepts arbitrary integer versions; `Appearance.from_dict({'schema_version': 999})` returns a v999 object interpreted using v1 fields/defaults. 5. **NEEDS-FIX — saved model instances bypass normalization (medium).** `src/appearance/integration.py:17` returns Appearance instances unchanged, and migration at line 88 uses that path. Pickle restores model fields directly, bypassing `from_dict`, so stale catalog IDs in a saved Appearance do not receive the promised safe defaults on load. Normalize supported-version existing instances through the validated model path without rerolling identities. Test an instance with an unknown feature/accessory ID, not just JSON dictionaries.

6. **NEEDS-FIX — migration gives older biological children newborn styling (medium).** `src/appearance/integration.py:102` calls inheritance regardless of actual age; `src/appearance/generate.py:119` always applies baby styling (buzz/bald, no accessories). Preserve styling of already-established appearances.

7. **NEEDS-FIX — test setup permanently replaces process-wide input (low).** `tests/__init__.py:10` installs a lambda on `builtins.input` without restoring it.
